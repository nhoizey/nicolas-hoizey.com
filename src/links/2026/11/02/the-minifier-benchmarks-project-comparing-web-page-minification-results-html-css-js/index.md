> The Minifier Benchmarks Project is a community-maintained collection of web page minification benchmarks, stewarded by [Jens Oliver Meiert](https://meiert.com/) ([context](https://dev.to/j9t/on-the-need-for-neutral-maintained-minifier-metrics-5715)). It enables to compare available tools, inspect tests, and make benchmarks and minifiers better. Minifier authors are invited to add their tools and become co-owners.
